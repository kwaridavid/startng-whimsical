Any static browser game works — HTML, JavaScript, three.js, Phaser. Players bring their start.ng character, scores and friends.

Build it

Make something small and fun. Any static browser game goes — no backend needed, no framework required.

1
🐙

Push it to GitHub

A public repo with a ready-to-play index.html at the top or in dist/, plus a cover.png for its card.

2
🚀

Publish it

One API call with your repo link, no key needed. Or hand your AI the docs and let it do the lot.

POST /api/publish

✅

Open the link you get back and it's live at yourgame.start.ng, with its own leaderboard if you want one. After that, every push updates it.
